Event 2

Summary Report: “FCAJ x Agentic AI Build Week: Show Up. Build. Pitch. WIN!”

Event Objectives

  • Gain exposure to the process of building practical AI-powered products within a short period of time.
  • Learn from hackathon teams about problem-solving, resource management, and teamwork.
  • Explore how AI can be integrated with backend systems, cloud infrastructure, and user interfaces to solve real-world problems.
  • Gain insights into technology trends and directions in the industry.

Speakers

  • One Team - Champion with a multi-channel AI Chatbot for food ordering
  • Signal Scout - Runner-up with a business strategy analysis platform
  • Plan V - AI Assistant for automatically generating system architectures for Solution Architects
  • 3KA - AI Camera system for crowd monitoring and coordination
  • Six Pillars - Multi-agent Anti-Money Laundering (AML) system for banks

Key Highlights

Multi-Channel Smart Food Ordering (One Team)

  • The solution directly addresses customer interaction barriers caused by requiring users to download an app or fill in complicated information.
  • The multi-channel chatbot (Zalo, WhatsApp) keeps users within familiar conversational environments, providing a seamless experience.
  • The system uses Agent Core to maintain context and combines Web Scraping to collect menu data, significantly reducing infrastructure costs.

Business Strategy Analysis (Signal Scout)

  • The project developed a platform that collects and consolidates scattered data to evaluate competitors’ business strategies.
  • The system combines Crawling Agents, Data Processing to filter noise and reduce hallucination, and a React Dashboard deployed on AWS Amplify to visually present ROI forecasts.

AI Generative Assistant for Cloud Architecture (Plan V)

  • A tool that automates the infrastructure design process for Solution Architects (SA).
  • With only a natural language description, the AI can automatically generate architecture diagrams, estimate costs, and generate Terraform infrastructure code for direct deployment on AWS.

Monitoring and Security Solutions (3KA & Six Pillars)

  • 3KA: Integrates Computer Vision with AWS Fargate to monitor crowd movement in real time and automatically alert areas at risk of congestion at airports or events.
  • Six Pillars: Uses an Adaptive Workflow Engine with three AI Agents (profile verification, transaction flow analysis, and sanctions screening) to filter false anti-money laundering alerts, saving banks hours of manual analysis.

Key Takeaways

User Experience (UX/UI) Mindset

  • One of the most important lessons came from One Team’s solution: complex AI technology behind the scenes should ultimately serve the goal of reducing barriers for end users.
  • Allowing customers to order directly through Zalo/WhatsApp instead of requiring them to download a separate application is an excellent example of user-centered design thinking.

Software and Cloud Architecture

  • The event demonstrated the power of combining distributed architectures, such as microservices, with the AWS platform.
  • The way teams used API Gateway, Lambda, Fargate, and React Dashboard demonstrated a complete workflow from AI processing in the backend to intuitive data visualization in the frontend.

Short-Term Project Management Skills

  • The participating teams demonstrated that within a limited timeframe, defining and controlling the project scope (scope limit) is extremely important.
  • Building a functional Minimum Viable Product (MVP) provides much more convincing value than pursuing an ambitious idea that cannot operate effectively in practice.

Application to Work

  • Frontend Development: Apply React and React Native to build smooth, intuitive, and cross-platform AI data visualization interfaces (dashboards), similar to how the teams utilized AWS Amplify.
  • Microservices Architecture: Apply the approach of breaking down tasks into independent agents connected through API Gateway to optimize performance for large-scale and complex systems.
  • Experience Optimization: Apply AI tools to UX/UI analysis and design workflows in Figma, while integrating AI into source code to automate software testing (automated testing).
  • Technical Planning: Use technical diagramming tools such as PlantUML to model systems and data flows before writing code, learning from the structured workflow of multi-agent systems.

Event Experience

  • The fourth year of university requires more practical perspectives on the technology market, and this hackathon event provided exactly that.
  • Watching the teams present their demos directly helped connect theories of software development, API integration, and interface design with highly commercializable products.
  • The competitive atmosphere, high-intensity working environment, and the teams’ ability to troubleshoot issues directly on stage provided great inspiration to continue developing deeper expertise in technology product development.

Lessons learned

  • The core of a successful technology product is its ability to solve the right market “pain point,” rather than simply incorporating the most complex technologies.
  • Managing input resources, from data and AI tokens to feature scope limitations, is an essential skill for successfully completing a project.
  • A smooth and intuitive user interface is one of the most important bridges for bringing complex AI solutions to a broader audience.
  • Teamwork, compromise, and commitment to a common goal play a decisive role in the success or failure of fast-paced technology projects.

Some event photos

Overall, AGENTIC AI BUILD WEEK was a highly practical and meaningful workshop. By analyzing products ranging from AI Chatbots to financial monitoring platforms, I gained a clearer understanding of the overall process of building modern system architectures: flexible in the backend, intelligent with AI, and highly optimized in the frontend user experience. This event provided a valuable foundation for developing a more comprehensive technology product development mindset.
