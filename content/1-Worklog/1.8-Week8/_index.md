### Week 8 Objectives:

* Master building and managing infrastructure using the AWS Cloud Development Kit (AWS CDK).
* Understand and practice deploying applications on AWS using Infrastructure as Code with AWS CloudFormation and AWS CDK.
* Build and deploy a Serverless backend using AWS Lambda, Amazon S3, and Amazon DynamoDB.
* Understand the process of developing a frontend integrated with Serverless APIs through Amazon API Gateway and AWS Lambda.
* Strengthen skills in deploying and managing modern application architectures on AWS.
